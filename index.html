🔐 UnityCipher Save Decryptor

Decrypts files encrypted with the UnityCipher.RijndaelEncryption library — salt + IV prefixed, PBKDF2-derived key, 256-bit-block Rijndael (not standard 128-bit AES — that's reimplemented here from scratch since browsers' Web Crypto only does the standard block size). Runs entirely locally; nothing is uploaded.
